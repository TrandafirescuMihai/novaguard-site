# NovaGuard — test marketing site

**Live site: https://novaguard-site.vercel.app**

Static landing page (HTML/CSS/JS, no build step) used as a vibe-coding practice project.
Every push to `main` deploys automatically to Vercel.

## Run locally

```
cd novaguard-site
python3 -m http.server 8000
```

Then open http://localhost:8000 (this serves your local copy, not the live site).
